# Design and production

## Use the current visual direction

Follow the supplied master, palette, dimensions and official assets. If none is supplied, choose a restrained professional visual system and record the assumption. Use consistent alignment, type hierarchy and reading order with layouts suited to the content. Avoid repeating decorative cards, generic icons and gradients merely because they are easy to generate.

Use genuine logos, exact sponsor/product spelling and correct artwork proportions. Show products at a size that communicates their identity and benefit. Verify screenshot crop instructions for this brief; retain original captures and provenance. Use realistic native styling for mocked search results rather than adding brand colors to a format that does not support them.

Choose evidence-bearing visuals. A competitor slide can pair observable ads with interpretation; an execution slide needs a large view of the experience; a budget slide needs an understandable comparison. Do not use dense tables throughout the deck. Avoid interchangeable images that could belong to any brand.

## Preserve editability

Keep slide titles, body copy, tables and essential analytical charts editable using native presentation objects where possible. Do not deliver an entire deck as flattened screenshots when an editable deck was requested. Images are appropriate for actual artwork, captured evidence and concept visuals. Keep generated concept labels and material disclosures readable.

Put core reasoning on the slide. Keep drafting instructions, internal reminders and validation logs out of the client-facing output. Use notes for supplemental detail and source context.

When copy does not fit, shorten or restructure before reducing type. Split only if the slide limit permits. Check contrast, source legibility, image quality and reading order at presentation scale.

## Render, inspect, repair

Use the available presentation toolchain or host presentation skill first. Render every slide. Inspect a montage for consistency and individual slides for clipping, overlaps, typography, meaningful screenshots, exact assets, chart labels and disclosures. Review the actual exported file, not only code or structural checks. Confirm the file opens and native elements remain editable where tools permit.

Re-render affected slides after fixes and verify that repairs do not break dependent slides. If rendering or application testing is unavailable, report that limitation explicitly; do not claim visual inspection occurred. A structural PPTX inspection is useful but cannot prove visual quality.
